# work/done/

Histórico de tareas cerradas. Mantén entradas mínimas — el `git log` es la fuente de verdad.

## Formato

`<num-del-backlog>-<slug>.md` con **una sola línea**:

```markdown
# Backlog #3 — Fix MediaField asterisk color

Cerrado 2026-05-28 · commit `abc1234` · PR #15
```

Si la tarea descubrió algo aprovechable para futuro (decisión, anti-patrón), **mejor un ADR o una nota en architecture/** que no un párrafo aquí.
